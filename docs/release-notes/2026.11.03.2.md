这些在库里标为 `pending`（待生效）：检索结果带琥珀色「尚未生效」标签，单条查询底部
给出黄色提示条，引文核验明确写「条文与库内一致，但尚未生效，不得作现行依据」，
MCP 的 `get_article` / `verify_citation` 返回 `is_pending` 与 `warning` 字段。

**到施行日当天自动转为现行，不需要再下载一次。** 同一部法的现行版与待生效版会并存，
检索默认取现行版（现行 > 已公布未生效 > 历史）。

### 顺带清掉两类解析残留

库里 224 部修改决定（341 条条文）的正文开头，原先带着解析管线留下的两类文字：

- 一行「（修改决定全文，共 N 项修改内容，项号以「一、二、三」排列）」的定位说明
- 决定标题被换行截断后的残片，如「《海南省环境保护条例》的决定」

这两类都不是法律原文，是抓取与解析过程中的副产物，此前被当成条文正文收进了
`content` —— 检索会命中它，律师复制条文到文书里也会带上。本次已一并清除
（标注 228 条、标题残片 225 条），生成端 `tools/fetch_mirror.py` 已改，后续不再产生；
清洗脚本留在 `tools/strip_amendment_note.py`，可重复跑、幂等。

清理后修改决定的正文直接以「某届人大常委会第某次会议决定：」开头，可直接引用。
全文索引已随之重建。

## 怎么更新

三条路，判断逻辑完全一致，按习惯挑一个：

```bash
python3 tools/check_update.py --update    # 命令行：查 + 装
./update.sh                               # 同上，自带环境探测
```

macOS 也可以直接双击仓库里的 **`更新数据.command`**，跑完窗口会停住显示结果。

装了本地查询界面（`web/index.html`）的，页面顶部会出提示条
「法规库 2026.10.31.1 → 2026.11.03.2，增量 2.6 MB」，点「立即更新」才装；
点「×」记在浏览器本地，同一版本不再弹。

服务启动时也会在后台查一次，不阻塞启动、断网不影响使用，结果缓存 1 小时。

## 该下哪个包

| 你的情况 | 下这个 | 大小 |
|---|---|---|
| 库是 2026.10.31.1 版 | `delta-2026.11.03.2.json.zst`（或 `.gz`） | 1.4 MB / 2.6 MB |
| 库更早，或第一次装 | `law_data-2026.11.03.2.db.zst`（或 `.gz`） | 514 MB / 676 MB |

`check_update.py` 会自己判断走哪条，不用手工挑。增量路径任何一步不通（格式不认、
解压失败、校验不过）都会自动回落到全量，不会把人卡在报错上。

**手动应用增量包**（不经脚本）：

```bash
python3 tools/apply_delta.py --delta delta-2026.11.03.2.json.gz
```

跑完会打出自检结果。这个动作是幂等的：同一部法同一天同一版已在库里就跳过，
重复跑、断点重跑、换机器再跑，都只会补建索引，不会插出两份同样的版本。

## 程序版本

数据可以自动装，**程序不会自动更新**——改的是源码，本地可能有未提交改动。
本版对应的程序是 **2.3.0**（tag `app-v2.3.0`）：

```bash
git pull && ./update.sh
```

2.3.0 新增的就是上面这套更新检查：`tools/check_update.py`、网页提示条、
`GET /api/law/update-status`、`POST /api/law/update-data`（后两个只允许本机调用，
经反向代理转发时会被 403 挡住）。

## 校验

五个文件，文件名必须与 `manifest.json` 的 `artifacts[].name` 逐字一致：

| 文件 | 大小 |
|---|---|
| `manifest.json` | 1.3 KB |
| `law_data-2026.11.03.2.db.zst` | 514.3 MB |
| `law_data-2026.11.03.2.db.gz` | 675.9 MB |
| `delta-2026.11.03.2.json.zst` | 1.4 MB |
| `delta-2026.11.03.2.json.gz` | 2.6 MB |

`fetch_data.py` 与 `apply_delta.py` 都会校验 sha256，不用手工算。

manifest 里另带 `app_version: 2.3.0` 与 `schema_version: 3`，可与本地 `/health` 对照。

## 已知边界

- **被废止的法规不会因「废止决定」入库而自动标为失效。** 本次新增的修改决定中有若干
  废止决定（如《海南省人民代表大会常务委员会关于废止〈海南省环境保护条例〉的决定》），
  决定本身已入库可检索，被废止的法规需在后续批次单独处理。
- **修改决定的正文只有决定条文本身**，不包含被修改法规的合并后全文。查具体条文请直接
  查被修改的那部法规，它的现行版已按修改决定更新。
- 少数早期入库的法规（33 条）正文末尾仍带原始来源网址（`http://law.npc.gov.cn/...`），
  属溯源信息，未改动。
- 正文来自国家法律法规数据库及其原始镜像，条文文字不改写、不补标点。发现错漏欢迎按
  `CONTRIBUTING.md` 提 issue，交原件即可。
